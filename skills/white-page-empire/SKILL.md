# White Page Empire

Draft disarming, high-utility text-only Google Docs and sales letters that capture reader interest and drive high-ticket conversions without visual distractions.

## Features

- **Disarming Design Strategy**: Rules for formatting documents (minimal colors, fonts, clean grids) to mimic private discoverable notes.
- **Intimacy Copy Framework**: Guidelines for writing in a raw, conversational, and direct tone of voice.
- **Inline Conversion Triggers**: Place soft, natural CTAs and booking pathways directly inside the body copy.

## Workflows

### 1. Structure the Text Sales Letter (Google Doc)
Organize the document to guide the reader from curiosity to conversion:
1. **The Hook (The Title)**: Focus on a specific outcome, e.g., "How we built X to solve Y in Z days."
2. **The Context (The Truth)**: Explain why you wrote this document (e.g., "I'm writing this because I'm tired of seeing founders make Y mistake...").
3. **The Core Mechanism**: Break down your system or framework with concrete numbers, screenshots, and steps.
4. **The Transition**: Pivot naturally to your offer:
   ```
   If you want to run this yourself, all the steps are above. 
   But if you want my team to build this system for you: [link to booking calendar].
   ```

### 2. Format for Maximum Readability
Format the document to look raw and discoverable:
1. **Fonts**: Use standard browser fonts (e.g., Arial, Calibri, or Roboto). Avoid custom designer fonts.
2. **Layout**: Keep headings clean, paragraphs short (1-3 sentences), and use bullet points for lists.
3. **No Heavy Branding**: Remove logos, animations, and massive footers that signal an "ad" or "sales pitch."

## Playbook Checklist

- [ ] **Step 1: Document Outline**
  - Define the single core thesis and value proposition of the document.
  - Draft the introduction clarifying the raw truth of why this was created.
- [ ] **Step 2: Copywriting**
  - Write the body text detailing the complete step-by-step system.
  - Keep paragraphs short, punchy, and conversational.
- [ ] **Step 3: Inline CTAs**
  - Place a booking link or email contact at the midway point and at the end of the document.
- [ ] **Step 4: Distribution Setup**
  - Set the Google Doc sharing settings to "Anyone with the link can view."
