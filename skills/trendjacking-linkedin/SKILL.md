# Trendjacking LinkedIn

Siphon massive professional traffic by positioning your offer at the intersection of industry announcements (e.g., major LLM updates) and target client pain points.

## Features

- **Seismic Event Mapping**: Standard workflow to track, analyze, and capitalize on tech announcements in real-time.
- **Teardown Copy Framework**: Structure viral posts that provide instant summaries, code samples, or benchmarks.
- **Comment-to-Lead Automations**: Call-to-value strategies that convert comment spikes into direct message leads and calendar events.

## Workflows

### 1. Build a Trend Teardown Post
Write a real-time summary post when a major industry event occurs:
1. **The Hook**: Announce the event and state a bold, contrarian take on how it impacts your ICP's business immediately:
   ```
   [LLM Name] just dropped. 
   Most founders will use it to write generic blog posts. 
   But the smart ones are using it to automate [Specific painful task]. 
   Here is the exact setup you need to clone it today:
   ```
2. **The Body (The Value)**: Detail 3-5 concrete takeaways, prompts, or code adjustments needed to implement the update.
3. **The Call-to-Value (The Lead Magnet)**: Offer a detailed PDF guide, template, or script to people who comment:
   ```
   I spent the last 6 hours building a [resource name] for this. 
   If you want it:
   1. Like this post.
   2. Comment "[Keyword]".
   And I'll DM it to you.
   ```

### 2. Convert Comments into Booked Calls
Manually or systematically distribute the asset and start conversations:
1. **Deliver the Asset**: DM commenters with the link:
   ```
   Hey [Name], saw you commented on the [Topic] post. 
   Here is the direct link to the guide/script: [Link].
   ```
2. **Pivot to Discovery**: Follow up with a helpful question 24 hours later:
   ```
   Did you get a chance to run that script? 
   We just integrated it for a client to cut [pain point] — let me know if you run into any setup bugs.
   ```

## Playbook Checklist

- [ ] **Step 1: Event Monitoring**
  - Track announcements from key tech entities (OpenAI, Anthropic, Google, Meta).
- [ ] **Step 2: Rapid Post Draft**
  - Draft and publish a breakdown post within 12 hours of the announcement.
  - Formulate a specific lead magnet (Google Doc or template) matching the post topic.
- [ ] **Step 3: Inbox Delivery**
  - Monitor comments and DM the asset link to all users within 24 hours of posting.
- [ ] **Step 4: Lead Nurturing**
  - Follow up with engaged commenters to pivot to discovery calls.
